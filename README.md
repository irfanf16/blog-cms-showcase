# Blog CMS — Laravel Content Platform

**CMS · Laravel**

A publishing platform with taxonomy, editorial workflow and role-gated publishing.

> **Source code is private.** This repository documents the architecture and engineering work.

## My role
Full-stack engineer

## Engineering highlights

**Taxonomy modelling.** Posts, categories and tags with many-to-many relationships and slug-based routing, indexed for tag and category listing pages.

**Editorial workflow.** Draft, scheduled and published states with role-gated publishing.

**Server-side tables.** Yajra DataTables for post management at scale, keeping the editor list responsive well past the point client-side filtering stops working.

**Rich media.** Image upload and transformation pipeline for post assets.



## Stack

`Laravel` · `PHP` · `MySQL` · `Blade` · `JavaScript` · `SCSS` · `DataTables`
